Kafeel Ansari Consultancy Website

Standalone static website. No installation, build step, server, or API keys required.

Preview
Open index.html in your browser.

Deploy on GitHub Pages
1. Create a GitHub repository (public for GitHub Pages on a free account).
2. Upload index.html, style.css, script.js and .nojekyll to its root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. GitHub displays the published address once deployment finishes.

For an account homepage, name the repository kafeelansari.github.io.
For a project repository, the site works under a repository subpath because all local assets use relative paths.

Editing
Content and contact links: index.html
Colors, fonts and responsive layout: style.css
Footer year: script.js

Email links open the visitor's email application. There is no contact form backend.
The website presents industry domains only. Client names, employer names, project names and engagement-specific details are excluded.
